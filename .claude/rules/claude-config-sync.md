# `~/.claude/settings.json` has two authors

Claude Code rewrites this file whenever settings change through the UI, and the
installed tools write into it as well. Copying it into the repository would
version somebody else's output. So the repository does not copy it - it **merges
into it**, through `home/dot_claude/modify_settings.json.tmpl`.

A `modify_` script receives the current target file on stdin and writes the new
content to stdout. chezmoi never overwrites the file, so nothing another author
put there is lost.

## What belongs to whom

| Keys | Author | Versioned |
|---|---|---|
| `model`, `tui`, `permissions`, `statusLine`, `enabledPlugins`, `extraKnownMarketplaces`, `cleanupPeriodDays`, `autoCompactWindow`, the `auto*` and `skip*` flags | you | yes, in the `modify_` script |
| `hooks` | `herdr`, `atuin`, `rtk`, `gh-axi`, `chrome-devtools-axi` | no - reinstalled by `run_onchange_after_60-agent-hooks.sh` |
| `autoMode` | Claude Code, generated per project | no |

**Adding a setting** means editing the jq object in the `modify_` script. Do not
`chezmoi add` or `chezmoi re-add` this file: that would replace the merge script
with a snapshot of the rendered result, which is the exact mistake the script
exists to prevent.

## Why `hooks` is not versioned

Four of the five hooks are a bare command name on `PATH`. Only herdr ships a
script, tracks its own version (`herdr integration status` reports it), and
overwrites its file on update. A copy in git cannot know any of that, and
`chezmoi apply` would keep reverting the tool's own upgrade.

The declaration still exists, just in executable form: `packages.yaml` says which
tools are installed, and the hooks script names the exact install command for each.

## Why `autoMode` is not versioned

Claude Code generates it by inspecting whichever project it was configured
against. It names that project's organisation, repository, services, protected
branches and the environment variables holding its secrets. None of that is
toolbox configuration, it goes stale the moment the project changes, and it does
not belong in a repository that describes two Macs.

If it is ever needed again, it is regenerated by Claude Code, not restored.
